## Етап 1. Іменники й дієслова

**Іменники** (усі з брифу):
місто, станція (прокату), велосипед, номер, звичайний велосипед, електричний велосипед, клієнт, ім'я, баланс, рахунок, хвилина, кількість хвилин, гроші, гривня, адміністратор, мережа

**Дієслова** (усі з брифу):
стоять (на станції), буває (звичайний/електричний), має (ім'я, баланс, номер), взяти (велосипед), покататись, повернути (велосипед), коштує, списуються (гроші), бачити (скільки велосипедів), заробила (мережа)

**Рішення щодо іменників:**

| Іменник | Клас / атрибут / не потрібен | Чому |
|---|---|---|
| станція | клас `Station` | має назву і велосипеди |
| велосипед | клас `Bike` | має номер і тип |
| клієнт | клас `Client` | має ім'я і баланс |
| номер | атрибут `Bike` | це просто число велосипеда |
| звичайний / електричний | атрибут `Bike` | це тип велосипеда |
| ім'я | атрибут `Client` | належить клієнту |
| баланс, рахунок | атрибут `Client` | це гроші клієнта |
| хвилина | число у функції | потрібна тільки для підрахунку ціни |
| гроші, гривня | ціна в `Payment` | потрібні тільки для підрахунку ціни |
| мережа | виручка в `Payment` | від неї треба тільки суму грошей |
| адміністратор | не потрібен | він тільки дивиться звіт |
| місто | не потрібен | ні на що не впливає |

**Рішення щодо дієслів:**

| Дієслово | Кому належить (клас або окрема функція) |
|---|---|
| стоять | `Station` (`add_bike`, `count`) |
| буває | `Bike` (атрибут `bike_type`) |
| має | не дія, це атрибути |
| взяти | `Rental.rent_bike()` |
| покататись | число хвилин у `Rental.return_bike()` |
| повернути | `Rental.return_bike()` |
| коштує | `Payment.calc_cost()` |
| списуються | `Client.charge()` |
| бачити | звіт у `main()` |
| заробила | `Payment.get_total_revenue()` |

## Етап 2. Картки класів

### Клас: Bike

| Що він ЗНАЄ (атрибути) | Що він ВМІЄ (методи) |
|---|---|
| number — номер | is_electric() — повертає True, якщо електричний |
| bike_type — "regular" або "electric" |  |

### Клас: Station

| Що він ЗНАЄ (атрибути) | Що він ВМІЄ (методи) |
|---|---|
| name — назва | add_bike(bike) — ставить велосипед на станцію |
| bikes — список велосипедів | take_bike() — повертає велосипед або None, якщо пусто |
|  | has_bikes() — повертає True, якщо є вільний велосипед |
|  | count() — повертає кількість велосипедів |

### Клас: Client

| Що він ЗНАЄ (атрибути) | Що він ВМІЄ (методи) |
|---|---|
| name — ім'я | top_up(amount) — поповнює баланс |
| balance — баланс у грн | can_pay(amount) — повертає True, якщо грошей вистачає |
| current_bike — велосипед, на якому катається | charge(amount) — списує гроші |

### Клас: Rental

| Що він ЗНАЄ (атрибути) | Що він ВМІЄ (методи) |
|---|---|
| payment — об'єкт Payment | rent_bike(client, station) — повертає (True, bike) або (False, "no_bikes") / (False, "already_riding") |
|  | return_bike(client, station, minutes) — повертає (True, cost) або (False, "no_bike") |

### Клас: Payment

| Що він ЗНАЄ (атрибути) | Що він ВМІЄ (методи) |
|---|---|
| total_revenue — загальна виручка | calc_cost(bike, minutes) — повертає ціну (2 або 5 грн/хв × хвилини) |
|  | pay(client, bike, minutes) — списує гроші з клієнта, додає у виручку, повертає ціну |
|  | get_total_revenue() — повертає загальну виручку |

Сценарій «Оля бере електричний велосипед на станції А, катається 20 хвилин і повертає його на станцію Б»:

| Крок сценарію | Хто відповідає (клас.метод або функція) |
|---|---|
| Оля бере велосипед на станції А | Rental.rent_bike(olya, station_a) |
| Перевірити, що на станції є велосипед | Station.has_bikes() |
| Забрати велосипед зі станції А | Station.take_bike() |
| Оля катається 20 хвилин | число 20 передається в return_bike() |
| Оля повертає велосипед на станцію Б | Rental.return_bike(olya, station_b, 20) |
| Поставити велосипед на станцію Б | Station.add_bike() |
| Порахувати ціну: 20 × 5 = 100 грн | Payment.calc_cost() |
| Списати 100 грн з балансу Олі | Payment.pay() → Client.charge(100) |
| Додати 100 грн у виручку мережі | Payment.pay() оновлює total_revenue |
